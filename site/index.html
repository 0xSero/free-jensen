How it works

01

One account, one signature

You sign through a GitHub issue form. Each signature is tied to your GitHub account's permanent ID, so renaming your account won't let you sign again. Duplicates are rejected automatically.

02

Counted one at a time

A GitHub Actions bot processes signatures strictly in sequence, one run at a time, so no two signatures can be counted at the same moment and none overwrite each other. Bots, organizations, and accounts less than 7 days old are refused.

03

Open and auditable

The code, the count, and every signature issue are public on GitHub. Anyone can check the tally. This page collects no cookies, uses no trackers, and stores no personal data beyond what you post on GitHub.
